# NEXORA — Resolution & FPS Tuner

تطبيق أندرويد بواجهة عربية يتيح تجربة خفض دقة العرض عبر Root أو Shizuku، وإنشاء قوالب إعدادات لبعض الألعاب والمحاكيات، وإيقاف تطبيقات خلفية تختارها. التوصيات مبنية على قواعد بسيطة محلية وليست نموذج ذكاء اصطناعي.

## حدود مهمة

- تغيير دقة العرض **ليس DLSS** ولا يضيف إعادة بناء بالذكاء الاصطناعي أو تعريف GPU. قد تتجاهله بعض الألعاب؛ لا توجد ضمانات لفريمات 90/120 أو خفض الحرارة.
- قوالب الإعدادات اقتراحات فقط؛ قد لا تقرؤها اللعبة أو قد تحتاج تركيباً يدوياً، ولا يحقن التطبيق تعريفات. لا يضمن التطبيق تفعيل 120Hz أو إزالة الظلال. اطلع على تعليمات كل قالب.
- زر Sharpness يولّد قالباً فقط ولا يغيّر حدة شاشة الجهاز. تغيير كثافة العرض ليس تحسيناً حقيقياً للحدة.
- Cool Mode يوقف التطبيقات المحددة، وقد تتوقف إشعاراتها حتى إعادة فتحها. لا يضمن منع الاختناق الحراري.
- عند تشغيل لعبة من داخل التطبيق، تتطلب محاولة الاستعادة التلقائية إذن الوصول لبيانات الاستخدام واستمرار خدمة المراقبة، وقد تفشل بسبب قيود النظام أو إيقاف الخدمة. التفعيل اليدوي وحده لا يراقب لعبة. يتوفر زر استعادة يدوي؛ إن لزم يمكن تشغيل `adb shell wm size reset`، علماً بأنه يزيل أي override سابق أيضاً.
- قبل الخفض يحفظ التطبيق إعداد الدقة الموجود مسبقاً ويحاول إعادته؛ إذا فشلت الاستعادة تبقى قابلة للمحاولة مجدداً. اختبر على جهازك ولا تحذف التطبيق أثناء تغيير الدقة.

## الاستخدام

1. Android 8.0 أو أحدث. ثبّت وشغّل Shizuku عبر التصحيح اللاسلكي أو ADB ثم امنح التطبيق الإذن، أو استخدم جهازاً بصلاحية Root. تنفيذ ADB من الكمبيوتر يدوياً بديل مستقل وليس صلاحية يمنحها التطبيق لنفسه.
2. اختر الدقة، وامنح إذن الوصول للاستخدام إذا أردت مراقبة لعبة، ثم شغّل اللعبة من القائمة. أو فعّل الخفض يدوياً واستعده بالزر عند الانتهاء.
3. ولّد قالب إعدادات للعبة، وانسخ المحتوى أو شاركه وراجع تعليماته قبل استخدامه.

## البناء والتحميل

يبني سير العمل `.github/workflows/build-apk.yml` نسختي APK على GitHub Actions. بعد نجاح البناء، افتح صفحة التشغيل في Actions وحمّل ملف `NEXORA-APK` من Artifacts. نسختا debug وrelease موقعتان بمفتاح تطوير، وليستا توقيع إصدار إنتاجي. لا ينشئ سير العمل GitHub Release.

للبناء محلياً: JDK 17 وGradle 8.7 وAndroid SDK 34، ثم `gradle :app:assembleDebug`.
