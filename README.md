# زيرون ستوديو | ZAYRON Studio

نسخة تجريبية 0.2 بقواعد مستقلة مستوحاة من اللهجة السعودية، وليست مجرد تبديل كلمة `print`:

```zyr
خل الاسم يكون "زيرون"؛
ورني "يا هلا في"، الاسم؛
لف ٣ مرات { ورني "اللفة"، الجولة؛ }
```

- [الدليل الشامل](docs/ZAYRON_GUIDE_AR.md) — قواعد 0.2 وأمثلة والانتقال من 0.1 وخارطة الطريق.
- [تطبيق أندرويد تجريبي 0.2](downloads/zayron-studio-0.2-debug.apk) — Android 6+، توقيع اختبار عام، لم يُختبر على جهاز حقيقي.
- التشغيل في المتصفح: `python3 -m http.server 8000 --bind 0.0.0.0` من جذر المشروع.
- اختبارات المفسر: `node tests/engine.test.js`.
- مشروع أندرويد في `android/`، وخطوات البناء في الدليل. GitHub Actions ينتج APK تجريبياً بعد رفع المشروع وتشغيل المهمة.

القواعد القديمة في 0.1 لا تتوافق تلقائياً مع 0.2. زر «استرجع كود 0.1» يظهر إذا وجد كوداً قديماً في نفس التخزين، لكنه لا يحوّله؛ احفظ نسخة خارجية قبل حذف التطبيق. هذا مفسر خاص بقواعد زيرون يعمل فوق JavaScript وليس مترجماً أصلياً أو بيئة عزل كاملة. محرك الألعاب والذكاء الاصطناعي والتصدير من كود زيرون إلى APK ومدير الحزم لم تُبنَ بعد؛ 1.0 هدف مستقبلي.
