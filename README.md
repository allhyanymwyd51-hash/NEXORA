# زيرون ستوديو | ZAYRON Studio

نموذج أولي تجريبي 0.1 للغة عربية ومحرر يعمل دون اتصال: اكتب في المحرر واضغط تشغيل. الرؤية المستهدفة هي زيرون 1.0، أما محرك الألعاب والذكاء الاصطناعي والمترجم الأصلي ومدير الحزم فلم تُبنَ بعد.

- [دليل زيرون الشامل بالعربية](docs/ZAYRON_GUIDE_AR.md)
- [تطبيق Android تجريبي APK](downloads/zayron-studio-0.1-debug.apk) — Android 6+، موقّع بمفتاح اختبار عام وليس للإنتاج. لم يُختبر على جهاز فعلي.
- الواجهة المحلية: `python3 -m http.server 8000 --bind 0.0.0.0` ثم افتح الخادم.
- اختبارات المفسر: `node tests/engine.test.js`.
- مشروع أندرويد في `android/`، وخطوات البناء في الدليل. GitHub Actions ينتج APK تجريبياً بعد رفع المشروع وتشغيل المهمة.

المفسر ينفذ مجموعة محدودة موثقة من الأوامر في JavaScript وليس بيئة عزل أمنية كاملة. احفظ نسخة خارجية من كودك قبل مسح بيانات التطبيق.
