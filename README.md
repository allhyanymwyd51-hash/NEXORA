# زيرون ستوديو | ZAYRON Studio

نسخة تجريبية **0.3**: قواعد سعودية وشاشة تشغيل مستقلة مع أساس ألعاب ثنائية الأبعاد، وأزرار لمس ولوحة مفاتيح. افتح المحرر واضغط «مثال لعبة» ثم «تشغيل الكود» لتجربة صيد النجوم.

```zyr
خل س يكون ٤٨٠؛
خلفية("#10162d")؛
سالفة حدث(زمن) {
  لو مضغوط("يمين") { س يصير س + ٢٥٠ * زمن؛ }
}
سالفة ارسم() { دائرة(س، ٢٧٠، ٢٠، "#a78bfa")؛ }
وقت_التحديث(حدث)؛
وقت_الرسم(ارسم)؛
```

- [الدليل الشامل ومراجع واجهة 2D](docs/ZAYRON_GUIDE_AR.md)
- [مثال لعبة صيد النجوم](examples/صيد-النجوم.zyr)
- [تطبيق أندرويد تجريبي 0.3](downloads/zayron-studio-0.3-debug.apk) — Android 6+، توقيع اختبار عام، لم يُختبر على جهاز حقيقي.
- التشغيل في المتصفح: `python3 -m http.server 8000 --bind 0.0.0.0` من جذر المشروع.
- الاختبارات: `node tests/engine.test.js` و`node tests/game.test.js`.
- مشروع أندرويد في `android/` وخطوات البناء في الدليل.

هذا أساس محدود وليس إصدار 1.0 مستقراً. لا يوجد محرك 3D أو تدريب ذكاء اصطناعي أو إخراج APK مستقل من مشاريع زيرون. المفسر يعمل فوق JavaScript وليس بيئة عزل أمنية كاملة. أكواد 0.2 متوافقة، ويظل الكود المحفوظ في التخزين المحلي متاحاً؛ احتفظ بنسخة خارجية قبل إزالة التطبيق.
