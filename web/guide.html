دليل البداية · نسخة تجريبية 0.2

يا هلا في زيرون.

زيرون لغة تجريبية بقواعد مستقلة مستوحاة من اللهجة السعودية، يشغلها مفسر محلي. هذا نموذج أولي، وليس إصدار 1.0 أو مترجماً أصلياً.

١. أول سطر

ورني "يا هلا بالعالم"؛

«ورني» تعليمة مباشرة بدون أقواس. اختم التعليمات بـ ؛. أمثلة زيرون 0.1 القديمة لا تعمل بصيغتها القديمة في 0.2.

٢. خلّ المتغير يكون

خل الاسم يكون "نورة"؛
خل الرصيد يكون ١٠؛
الرصيد يصير الرصيد + ٥؛
ورني "يا هلا"، الاسم، "رصيدك"، الرصيد؛

٣. اتخذ قرارك

لو الرصيد أكبر من ١٠ {
  ورني "كفو!"؛
} غير كذا {
  ورني "باقي شوي"؛
}

٤. لفّ عدد محدد

لف ٣ مرات {
  ورني "اللفة"، الجولة؛
}

كل لفة لها المتغير المحلي «الجولة» يبدأ من ١. عدد اللفات يُحسب مرة واحدة قبل البداية. للتكرار المشروط استخدم «دام».

٥. سالفة ترجع قيمة

سالفة ضاعف(عدد) {
  رجع عدد * ٢؛
}
ورني ضاعف(٥)؛

ادعمنا أنواع الأعداد والنصوص و«صح» و«غلط» و«فاضي». استخدم «و» و«أو» و«مو»، و«يساوي» و«أكبر من» و«أقل من»، أو رموز المقارنة. التعليقات تبدأ بـ // أو #.

٦. حدود النسخة

محرك الألعاب والذكاء الاصطناعي والتصدير من كود زيرون إلى APK والقوائم والكائنات ونظام الحزم غير مبنية. المفسر له حد تنفيذ لكنه ليس بيئة عزل أمنية كاملة.
